Implemented Shamir's Secret Sharing Scheme (SSSS) from scratch in Java. A secret is split into N shares where any K shares can reconstruct the original but K-1 shares reveal nothing. Built to solve the real-world problem of key management — no single point of failure. Uses finite field arithmetic over GF(256) for share generation and Lagrange interpolation for reconstruction. The name is a Demon Slayer reference because why not.

Java Cryptography Shamir SSS DSA GF(256)

Started this because quantum computing felt intimidating and vague — so I built the smallest possible thing that was still real. A qubit put into superposition via a Hadamard gate is genuinely in both states at once; measuring it collapses to 0 or 1 with true physical randomness — not a PRNG, not an algorithm. The result is more fundamentally random than anything a classical computer generates natively. Extended to N qubits: 3 qubits → 8 outcomes each at ~12.5%, showing the exponential scaling that makes quantum computing powerful for certain problems. First project in a personal series toward understanding quantum algorithms from first principles. Written with Qiskit 2.3 + Qiskit Aer on Python 3.13.
